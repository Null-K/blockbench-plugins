# blockbench-plugins

你可以按照需求自行选择版本  
当前安装插件版本号可以在 `Blockbench` 插件窗口内查看

> 新版本包含旧版本的所有功能

### hsl_shift_brush.js
- https://www.bilibili.com/video/BV1sq3V6yEsF
    - 1.0.0 初始版本

### pathtracer.js
- https://www.bilibili.com/video/BV1EZ3762EV9
    - 1.4.0 添加模式按钮，默认为低采样预览减少卡顿，确认效果后可以切换到高清模式保存图片
    - 1.3.0 添加后处理效果：泛光、锐化、暗角、胶片（胶片 ❌，更多噪点 ✅）
    - 1.2.0 修改降噪算法，提高强度上限
    - 1.1.0 添加渲染面功能，兼容负尺寸模型
    - 1.0.0 初始版本
